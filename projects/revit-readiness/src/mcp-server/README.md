# MCP host

This net10.0 library consumes official `ModelContextProtocol` **2.2.0** with an exact constraint and lockfile. It supplies an SDK stdio host, cancellation-aware input and optional byte-preserving wire capture. A separate [synthetic probe](../../tests/mcp-probe/Program.cs) tests the connection without Revit. Production Revit tools, IPC and the net48 adapter are not implemented yet.

The author approved revision 2, selected Native execution and subsequently directed the [revision 3 desktop compatibility amendment](../../../../docs/superpowers/specs/2026-10-20-desktop-compatibility-amendment.md). [Fresh CP0 evidence](../../docs/verification/2026-10-20-desktop-mcp-compatibility.md) passes in both actual desktops. `McpProtocolPolicy.Compatible` maps to the SDK default `ProtocolVersion=null`; `Strict20260728` uses the same host path for regression checks. The separate probe accepts `--require-protocol 2026-07-28` for strict testing. Production has no participant protocol selector. Compatible July and strict old-version rejection remain tested. Task 2 is next; this is not Revit acceptance.

Run `& ./projects/revit-readiness/scripts/Test-McpBridge.ps1 -Suite Protocol` from the repository root. See the [agent procedure](../../../../docs/how-to/verify-desktop-mcp-compatibility.md) for tests, temporary configuration, evidence and recovery, and the [participant story](../../../../docs/tutorials/07-test-desktop-compatibility-first.md) for how the author directed this experiment.

`CancellableInputStream` is an attributed adaptation of the **C# SDK 2.2.0** helper. The host and trace composition are original lab code. SDK parsing/dispatch is consumed as a package; TypeScript SDK 1.26.0 and other Revit bridges remain precedents only. Read [dependency research](../../../../docs/research/mcp-sdk-dependencies.md) and [retained notices](../../third-party/mcp/README.md). The fresh registry observation found 2.3.0; the approved 2.2.0 pin was retained.

The host owns raw streams and trace sinks; SDK wrappers borrow streams. A canceled Windows read may outlive its waiter, so it retains a private buffer and cannot be reused. Shutdown tests require natural exit with stdin still open in both trace modes. Captures are opt-in, bounded, local and use CreateNew; diagnostics go to stderr. None of these tests establishes live Revit acceptance. Continue through the [review hub](../../../../docs/superpowers/reviews/revit-mcp-bridge/README.md) at Task 2 after this CP0 pass.
