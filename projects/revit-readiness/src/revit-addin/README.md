# Revit add-in

The first implementation is `BimAgentLab.RevitProbe`, a C# x64 `net48` library for Revit 2024. It provides **Add-Ins > External Tools > BIM Agent Lab - Read-only probe**.

The command reports project identity, Revit build, and counts of non-type elements in the Walls and Ceilings categories. It reads the entire active host document, excludes linked documents, and applies no view/selection/phase/design-option/level filter or result limit. `TransactionMode.ReadOnly` enforces read-only execution; the dialog also reports the document's modified flag before and after the reads.

Follow the [agent setup guide](../../../../docs/how-to/build-read-only-revit-command.md) for build and installation, the [acceptance procedure](../../tests/read-only-probe.md) for testing, and the [verification record](../../docs/verification/2026-10-20-read-only-probe.md) for observed results. API references come from the installed Revit 2024 folder with Copy Local disabled. The probe has no NuGet packages.

`BimAgentLab.RevitReadiness` adds **BIM Agent Lab - Required type information** as a separate command and project. Its reader resolves an explicit checklist scope, reads type parameters by built-in IDs/shared GUID, and passes normalized observations to the core. Its command writes local JSON/text evidence, invokes the isolated [Excel exporter](../excel-report/README.md), and displays findings under `TransactionMode.ReadOnly`. Follow the [agent readiness guide](../../../../docs/how-to/build-required-information-check.md) and [acceptance procedure](../../tests/required-information.md).

Both project files list their source files explicitly so the original probe remains independently buildable. The fixture editor lives separately under `tests/fixture-tools` and is installed only with an explicit switch. Task 5 adds explicit Start/Stop bridge commands, a no-listener-on-load application entry, ExternalEvent dispatch and context-bound calls to the existing reader. The new classes compile but are not installed; Task 7 must add their manifests and runtime files with recovery. No MCP SDK runs inside Revit. See the [adapter procedure](../../../../docs/how-to/build-and-verify-revit-adapter.md), [verification](../../docs/verification/2026-10-21-revit-adapter.md) and [pending host acceptance](../../tests/mcp-host-acceptance.md).
