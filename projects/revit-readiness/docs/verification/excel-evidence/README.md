# Excel verification evidence

See the [dated acceptance record](../2026-10-20-excel-output.md) for what was tested, failures, corrections, and outstanding checks. Red/green console logs preserve the first test cycle. The independent comparison reads the XLSX ZIP/XML and compares values with the saved reports, native schedules, and separately authored oracle. Package/license originals live in [third-party](../../../third-party/README.md).

Workbooks generated by `Test-Readiness.ps1` live under ignored `tests/excel/bin/outputs`; host workbooks live beside the ignored sample RVTs. No Autodesk or dependency DLLs, NuGet packages, or working models are tracked here. JSON comparison records preserve workbook hashes; rebuilding a workbook may change ZIP metadata/hash while preserving its checked content.

The three `BAL-info-*.readiness.json` files here are fresh reports from the successful Excel acceptance runs. `host-comparison.json` compares their host-generated workbooks against the unchanged native TSVs and literal oracle; `offline-comparison.json` uses the earlier reports in [required-information-evidence](../required-information-evidence/README.md). Native schedules are retained there rather than duplicated here. The RVT hash comparison ties both sets to the same unchanged sample files.

Revit dialog screenshots record the successful host exports. The five `excel-*.jpg` images record all four worksheets and the [coverage footer](excel-coverage-footer.jpg) in native Excel. The initial failed dialog and fixture-first red/green logs preserve issues found and corrected during development.

To recreate workbooks from these newer reports after building, run the exporter with each report JSON and a destination `.xlsx` under the ignored `tests/excel/bin/outputs/` directory. To re-run the independent comparator against that set, copy these three JSON files and the six original native TSVs into one ignored verification directory, generate the three matching workbook names, and supply that directory as both comparator arguments. Do not overwrite the original acceptance evidence.
