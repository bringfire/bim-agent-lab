This copy never supplies DTO values or evidence. Net10 uses `JsonDocument` for the complete-input check. Both targets materialize only allowlisted plain DTOs from the original validated infoset. Bounded encoding and the private contract remain unchanged; no NuGet package or copied upstream source was added.

Source inspection explains the observed behavior; executable tests establish it in our target runtimes. This source is a research reference, not adopted code.
