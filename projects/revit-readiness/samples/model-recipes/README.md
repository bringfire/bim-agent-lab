# Preparing the readiness demonstration

Status: proposed recipe, not an executed preparation record.

Follow the [controlled cases and preparation sequence](../../docs/demo-questions-and-sample-model.md). Inspect the sample's actual parameters, types, phases, and levels before selecting a demo area. Use explicit case IDs to define scope independently of view visibility.

Prepare a complete baseline, then a separate copy containing the deliberate defects. Duplicate changed types so unrelated sample elements remain unaffected. Preserve a reset copy.

Record the source model/version, working-copy identity, level and phase, element UniqueIds, type mappings, custom parameter GUIDs/bindings, requirements, and deliberate edits. Establish expected quantities through independent geometry checks and Revit schedules. These records will make the eventual recipe reproducible on another workstation.
