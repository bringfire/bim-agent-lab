# Repository utilities

Project-specific [Revit environment, build, and install scripts](../projects/revit-readiness/scripts/README.md) now support the first working command. No shared repository utility has been introduced. The [clone guide](../docs/how-to/clone-research-repositories.md) provides the reference-acquisition workflow.

Add a script when a repeated operation has established inputs, outputs, and failure behavior. Document prerequisites and verification with it. Shared repository utilities belong here; application-specific build or deployment scripts belong in their project.
