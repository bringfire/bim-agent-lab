# Historical planning archive

These are original workshop-planning artifacts, retained to explain how the seminar and example evolved. Their bytes are preserved; they are not the current product specification, support matrix or agenda.

In particular, the organizer brief and proposal PDF describe intended Revit **2022–2027** support, broader inventory/physical-condition/quantity features, and read-only use on live projects. Those statements were aspirations in the early proposal. The implemented example checks required wall/ceiling type information; the recorded live baseline is **Revit 2024 build 24.3.60.12**. Read-only does not establish suitability for an untested production model. Revit 2026 is planned next; 2026/2027 support has not been verified.
