# Lesson template

1. **Purpose:** the BIM problem and what the learner will be able to do.
2. **Starting point:** required knowledge, setup, and the actual source commit or release.
3. **Prompt:** label it as an actual prompt, excerpt, or suggested teaching prompt.
4. **Why it works:** constraints, context, acceptance criteria, and useful agent direction.
5. **Work and decisions:** relevant source locations, discoveries, corrections, and tradeoffs.
6. **Verification:** independent expected result, actual checks, and limitations.
7. **Checkpoint:** the real commit and the diff that contains this completed change.
8. **Practice:** one small extension with a checkable result.

Add the lesson to the learning path and link back to the worked example. Do not label a planned feature as a completed walkthrough.
