The native interop wrapper, descriptor catalog, endpoint, client and lazy provider are original lab code using installed framework APIs. No new NuGet dependency, copied upstream implementation or Autodesk binary enters either runtime. Revit remains net48; the external MCP host remains net10.0 with official C# SDK 2.2.0. TypeScript SDK 1.26.0 remains precedent-only. The earlier observed SDK update is not an instruction to upgrade during this task.

Two experiments shaped cancellation ownership. Combining explicit pipe disposal with framework cancellation callbacks produced a net48 `CancelIoEx`/closed-handle exception. Removing explicit closure left a pending operation hanging. The implemented strategy uses owner-triggered pipe closure for connected I/O, passes no competing native cancellation token, and awaits the resulting I/O completion before releasing the worker. Connect retains its own two-second limit and the original lifetime's cancellation. This is a tested implementation decision, not a claim that every framework stream ignores cancellation.

Real Windows tests cover local access denial using an intentionally foreign-logon DACL, descriptor ACL inspection, actual peer PID rejection, cleanup failures and stalled-slot recovery. A real second-logon client and a remote-machine attempt were **not performed**; no accounts or security policies were changed. Native remote-rejection configuration is source-reviewed, not represented as observed cross-machine denial.
